# Floresta do Crepúsculo — Arquivo do Twilight

Site estático do manual do jogador.

## Deploy no GitHub Pages

1. Crie um repositório e envie `index.html`, `style.css` e `script.js`.
2. Settings → Pages → Deploy from a branch → `main` / root.
3. Pronto em 1–2 minutos.

## O que tem

- Layout horizontal (nav em pills, conteúdo largo)
- Busca em tempo real
- Universo, Mecânicas, Depravações e Ficha
